## Decisions

Confirmed correction: the journal-volume comma is upright in APA display and HTML clipboard export. Whitespace-only volume/issue fields no longer create empty parentheses or bare MLA labels. New exports escape metadata as text, preserve correct italic spans and provide an honest plain-text fallback message.

Existing correct/conservative behavior retained: author order and Unicode, initials/hyphens/suffixes, group names without guessed surname splits, 20/21+ APA threshold, article identifier priority over PDF-local pages, absent optional fields, nested quotation punctuation, DOI normalization and explicit title editing. No bulk metadata rewrite or automatic title casing was justified.

Unresolved gates: authoritative MLA 9 article-number and detailed page-abbreviation review; publisher byline for MLA-06; publisher metadata for MLA-07; missing month/season precision; scientific italic spans within titles; complete full-byline checks where only publisher extracts were accessible. The pilot must describe citations as drafts needing verification, not certified finished references.
